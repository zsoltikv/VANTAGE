## ✨ Features

- **Dual Collections** - Track completed games and wishlist separately
- **RAWG API Integration** - Search and add games with full details
- **Glassmorphic UI** - Elegant glass-effect cards with hover animations
- **Animated Stars** - Dynamic starfield background
- **Fully Responsive** - Works seamlessly on all devices

## 🛠️ Tech Stack

- HTML5
- TailwindCSS
- Vanilla JavaScript
- RAWG API

## 🚀 Quick Start
```bash
# Clone the repo
git clone https://github.com/zsoltikv/vantage.git
cd vantage

# Open index.html in your browser
# Add your RAWG API key in main.js
```

## 📝 Setup

Replace the API key in `main.js`:
```javascript
const API_KEY = 'YOUR_RAWG_API_KEY';
```

## 💡 Usage

1. Open the site in your browser
2. Click **Search** to find games
3. Add games to **Completed** or **Wishlist**
4. Switch tabs to view your collections
